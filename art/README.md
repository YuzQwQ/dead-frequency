# 资产制作

## 从侧视稿到游戏

1. 画一张独立 SVG，用侧视轮廓确定识别特征、色块和比例。需要活动部件时，在选案里先留出活动空间。P-12 目前采用根据用户多视角参考图整理的 [重制侧视稿](p12-reference.svg)，上一版的三款方案保留在 [初版概念稿](p12-concepts.svg)。
2. 把选案拆成命名部件、材质和节点层级。`src/model-parts.ts` 支持方盒、八边圆柱、侧面轮廓挤出和分组。轮廓使用前向／向上的二维坐标，厚度与倒角单独填写。`src/models/weapons.ts` 里的 P-12 配方是可以序列化的普通数据，保留了对应概念稿、局部变换、材质和用于动画的节点名。未来的可视化编辑器可以读写同一结构。
3. 在 `AssetFactory` 注册配方。预览页和游戏通过同一工厂创建模型并共享网格、材质定义。`view` 标记控制手部、枪托等部件适用的视角，泵柄和支撑手共享活动节点。战斗只向渲染器提供动画进度。枪口标记、瞄准高度、持枪取景和泵柄行程都属于外观配方。
4. 用正交侧视核对剪影，用透视检查厚度与色块，再在实际关卡中检查持枪、瞄准和装填。P-12 重制版采用长楔形木托、独立斜握把、一体式木质泵柄和接近齐头的双层前部轮廓。第一人称保留同一枪身与握把，只绘制枪托前段，给瞄准视野留出空间。

## 预览方式

[简易小刀侧视稿](knife-reference.svg)依据用户提供的左下和右下参考图制作。配方在 `src/models/knife.ts`，第一人称动作在 `src/knife-motion.ts`。模型通过同一资产工厂创建，持刀手套只在第一人称中渲染。

运行 `pnpm dev` 后打开 `/art/preview.html?weapon=p12`。选择侧视或透视，拖动泵柄滑块可以检查整个回拉范围。预览页用于开发期审核。

安装 Playwright Chromium 后执行 `pnpm art:preview p12`，会生成侧视、透视、泵柄回拉末端、第一人称持枪和瞄准截图，并在隔离的浏览器存档里验证射击与换弹。截图保存在 `art/previews/`。更换参数可预览已注册的其他枪械。
