# 资产制作

## 从侧视稿到游戏

1. 画一张独立 SVG，用侧视轮廓确定识别特征、色块和比例。需要活动部件时，在选案里先留出活动空间。Remington 870 目前采用根据用户多视角参考图整理的 [重制侧视稿](p12-reference.svg)，上一版的三款方案保留在 [初版概念稿](p12-concepts.svg)。
2. 把选案拆成命名部件、材质和节点层级。`src/model-parts.ts` 支持方盒、八边圆柱、侧面轮廓挤出和分组。轮廓使用前向／向上的二维坐标，厚度与倒角单独填写。Remington 870 与小刀的 JSON 配方保存在 `src/models/`，编辑器和游戏都读取这两份配方。
3. 在 `AssetFactory` 注册配方。预览页和游戏通过同一工厂创建完整武器模型。用 `hand: true` 标记手部或手部分组，第一人称在同一武器上显示这些部件。支撑手是泵柄的子节点，会随泵柄移动。枪口标记、瞄准高度、持枪取景和泵柄行程属于外观配方。
4. 用正交侧视核对剪影，用透视检查厚度与色块，再在实际关卡中检查持枪、瞄准和装填。Remington 870 的长楔形木托、独立斜握把、一体式木质泵柄和双层前部轮廓在各视图共用一套几何。

## 预览方式

[M4A1 黑灰侧视稿](m4a1-reference.svg)保留了用户参考图的提把、三角准星、带肋护木和镂空枪托。游戏与编辑器共用 `src/models/ar56.json`，执行 `pnpm art:preview ar56` 可复现侧视、透视和第一人称预览。

[Glock 17 侧视稿](glock17-reference.svg)的模型配方为 `src/models/k9.json`。按枪口至套筒尾端的总长 1 设计，套筒宽 0.158、高 0.144，握把中段沿 Z 轴的截面厚度为 0.200。执行 `pnpm art:preview k9` 可生成预览。

[简易小刀侧视稿](knife-reference.svg)依据用户提供的左下和右下参考图制作。配方在 `src/models/knife.json`。刀身用一个侧面轮廓生成，编辑器可设置「主体厚度」「刃面宽度」和「刃口厚度」。刀面槽纹、铆钉和橙色尾标各用一个条目控制左右两侧，编辑器的「距中线」同时调整两边。第一人称动作在 `src/knife-motion.ts`，手部仍可单独调整。

运行 `pnpm dev` 后打开 `/art/preview.html?weapon=p12`。选择侧视或透视，拖动泵柄滑块可以检查整个回拉范围。预览页用于开发期审核。

安装 Playwright Chromium 后执行 `pnpm art:preview p12`，会生成侧视、透视、泵柄回拉末端、第一人称持枪和瞄准截图，并在隔离的浏览器存档里验证射击与换弹。截图保存在 `art/previews/`。更换参数可预览已注册的其他枪械。

## 物品图标

`src/props.ts` 用四种基元（方盒、八边柱、圆锥、八面体）拼出收集品与装备类（头盔、耳机、弹挂、背包）的模型，和场景里的方块资产共用一套材质。图标不是另画一套图，而是给这些模型拍照：

- `npm run icons` 会启动一个临时开发服务器，逐件打开 `art/icon.html?id=<物品>&view=<视角>`，等 `#stage[data-ready]` 后按模型包围盒的投影裁剪，输出透明 PNG 到 `assets/icons/`。
- 武器走 `side`：正交相机放在 -X，屏幕上「右」是 +Z，而枪口朝 -Z，所以枪口落在画面左边。
- 收集品走 `iso`：方位 45°（+X/-Z 对称，近似等轴测），俯角 28°（25°~30° 轻俯视），长焦弱透视（垂直 FOV 约 9.5°，相机距离约为画面半高的 12 倍）。这样正面（-Z）与右侧（+X）对称可见，顶面收窄但不会被压成一条线，方块边缘还留一点近大远小。想换角度不用改代码：`ICON_ELEV` / `ICON_AZIM` / `ICON_PERSP` 环境变量会透传给渲染舞台，例如 `ICON_ELEV=25 npm run icons`。
- 裁剪很关键：步枪是 16:5 的长条，保留 512×512 方形画布的话，缩到 40px 格子里只剩一条细线。
- 一张联系表会写到 `art/previews/item-icons.png`，用来一眼看出哪张糊了。
- `src/icons.ts` 静态 import 这些 PNG，离线单文件构建会把它们内联成 base64（43 张）。新增装备图标后可以只重渲染指定物品：`npm run icons -- helmetLight packTactical`。

## 建模编辑器

- 执行 `pnpm build:editor` 后双击根目录的 `建模编辑器.html`，或通过开发服务器打开 `/art/editor.html`。静态构建也包含 `art/editor.html`。
- 左侧选择部件，使用视口操作轴移动或旋转，右侧可精确输入位置、角度和尺寸。挤出部件支持拖动侧视轮廓点，或输入前向 U、向上 V 坐标。材质共用颜色，可先复制材质再改某一部件。
- 视口可切换透视、侧视、正视、俯视，以及「仅武器」或「武器和手部」。在部件列表选择手部会自动显示手部。新增手或手套时，可把对应分组的「部件归属」设为「手部」。泵柄滑块用于查看运动范围，回到零位后可以用操作轴编辑。
- 手臂和连指手套由连续的八边截面生成。选择手部的截面体后，可逐截面调整中心、宽度和厚度。袖口与袖身共用网格，另用材质区分。手部随各自的武器配方保存。
- 编辑过程自动保存草稿，草稿可撤销、重做。选择「打开配方」并授权关联 `src/models/p12.json` 或 `src/models/knife.json` 后，可以主动点击「写回文件」。也可「导出 JSON」后在文件管理器替换同名文件。浏览器草稿不会自动覆盖项目，开发服务器和离线文件各自保存草稿。
- 开发模式可读取修改后的源配方。要更新双击游玩的游戏单文件，执行 `pnpm build:offline`。要让下一份编辑器单文件内置新配方，执行 `pnpm build:editor`。
