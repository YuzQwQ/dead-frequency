# Dead Frequency / 死寂频段

桌面浏览器上的单人第一人称搜打撤游戏。第一次潮汐过后的第四年，环礁湾 07 号转播站重新发出了停播前的呼号。玩家从南侧道路入场，在 15 分钟的静潮窗口内搜索仓库、医疗站、调度楼、车间和信号研究室，并从北侧水闸或东侧公路撤离。

## 启动

### 双击离线版

在文件管理器中用桌面浏览器打开项目根目录的 `死寂频段.html`。这一个文件包含游戏代码、样式和音效，可以复制到其他目录并离线使用。离线存档由浏览器管理，一般与该文件的路径关联。移动或重命名文件后，原路径的存档可能不会显示。

修改源代码后，运行 `pnpm build:offline` 重新生成单文件。

美术调试可双击 `建模编辑器.html`，或运行 `pnpm dev` 后打开 `/art/editor.html`。生成编辑器单文件和将修改导入游戏的步骤见 [建模编辑器](art/README.md#建模编辑器)。

局内切到小刀后按 **F8**，可在当前相机中调 FOV、整体与右臂局部变换、手腕、ItemSocket 和缩放。默认姿势与呼吸、摆动设置来自 `src/models/knife-viewmodel.json`。调试时暂停行动，可预览呼吸、模拟步行或回到静态。面板支持恢复默认和导出 JSON，按 **F8** 或 **Esc** 返回现场。

「右手关节」可分别调整手臂根部、手腕、掌心、四指三节和拇指的角度，单位为度。勾选「显示旋转轴」可在当前画面检查各关节的轴线。

### 本地开发与预览

需要 Node.js 22.12+ 和 pnpm 11。建议使用 Node.js 24。游戏需使用支持 WebGL 2 和 Pointer Lock 的桌面浏览器。

```sh
pnpm install --frozen-lockfile
pnpm dev
```

打开 Vite 打印的本地地址。首次出击时浏览器会锁定鼠标并启用声音。若自动锁定未获得许可，可点击「返回现场」重试。

```sh
pnpm build
pnpm preview
```

构建产物位于 `dist/`。可以把该目录放到任意静态 HTTP 服务的根路径或子路径。开发和构建需要安装依赖，构建后的游戏由本地打包的前端代码和音频运行。

### 多格库存

左键长按物品或移动约 4 px 开始拖拽，拖拽中按 **R** 旋转矩形物品。绿色表示可以放置或合并。红色区域和库存外松手会保留原位置。**Ctrl + 左键**在当前可见库存间快速转移，**Alt + 左键**快速装备。悬停查看摘要，双击打开详情。局内按 **Delete** 可丢弃悬停或选中的物品，贵重物品和装有物资的收纳装备需要确认。

按 **Tab** 打开装备页，可在装备、状态和地图之间切换。拖动角色预览可旋转模型。搜刮普通容器时沿用这套装备页，并在右侧显示容器库存。尸体搜刮展示双方的紧凑装备栏。整理库存期间行动计时和敌人仍继续运行，**Esc** 可逐层关闭详情、装备页或进入暂停。

库存尺寸和物品长宽在 `src/data.ts` 配置。仓库为 10×20。V4 存档记录装备实例、内部库存、格子坐标、方向及快捷键绑定。V1–V3 的随身物资迁移到穿戴中的 6×6 旧式背包。迁移或尺寸调整后放不下的物品可在「待领取物资」领取。

角色有四个独立的 1×1 口袋，以及头盔、耳机、护甲、弹挂、背包和两个武器槽。背包和弹挂的内部库存随装备转移。在仓库右键点击收纳装备可打开内部库存。先取出内部物品再出售装备。拾荒者死亡后保留实际装备、耐久、枪内余弹和随身物品，打开尸体可以双向拖拽装备和物资。

### 装备栏展示（V1.1）

装备槽自身就是物品卡片：顶部一条独立的类型标题栏，下方是完整展示区。槽内的物品格只负责图标与拖拽/右键命中，不再额外画一层库存格边框；名称（左上，单行截断）、耐久与余弹（右下）、耐久条（贴底）、快捷键（角落）全部覆盖式排布，槽位尺寸不随装备状态变化。空槽用低透明轮廓图标和轻微斜线纹理，已装备槽用稀有度色背景加整圈描边。

左侧以中央 3D 角色预览为核心：头盔、耳机在上方两侧，护甲与近战武器是两侧纵向槽，主/副武器是预览下方两条完整横向槽，枪图直接铺满槽面。右侧保持弹挂、口袋、背包的顺序，弹挂与背包装备卡放大并改用 3D 渲染图标，分区之间留明显间距，随身库存列可独立滚动。玩家与拾荒者尸体共用同一套展示规范（尸体面板为无 3D 预览的紧凑布局）。

卸下不再有常驻按钮，改用右键菜单或拖回库存。装备类物品图标同样由 `src/props.ts` 程序化建模、`npm run icons` 渲染。

## GitHub Pages

将本目录作为一个独立仓库的根目录推送至 `main`。在仓库 **Settings → Pages → Build and deployment → Source** 选择 **GitHub Actions**，随后运行 **Deploy Dead Frequency to Pages**。仓库里的工作流会安装锁定依赖、运行规则测试、构建并上传 `dist/`。Vite 的相对资源路径支持 `https://<账号>.github.io/<仓库名>/`。也可以把已构建的 `dist/` 发布到其他静态主机。

本地存档属于当前浏览器和站点来源。开发服务器、正式域名或不同端口各自保留自己的存档。

## 行动规则

- 在仓库与整备页拖拽装备到对应槽位。将对应弹药与医疗品放入弹挂或口袋，换弹和快捷使用会从这些位置取用。可以右键医疗品绑定至 **4–7**。初始配置有手枪、轻甲和补给，仓库另有一把霰弹枪。
- 搜索分两步：先面对容器站定片刻把箱盖撬开（移动、偏离目标或受伤都会打断），打开后面板里的物品逐件扫出来——扫描中的格子只有剪影，扫完才亮出图标与名字，期间点不动也拿不走。
- 容量按物品组计算，同口径弹药可堆叠。
- 物品栏统一用格子：单击看详情（分类、稀有度、重量、单价），右键出操作菜单，双击在容器与背包之间快速转移。仓库、交易和搜刮面板共用同一套操作，格子边框按稀有度整圈描边。
- 仓库按物品占格统计，可按分类筛选、按名称或描述搜索、按价值、稀有度、名称或重量排序。购买前会检查仓库的连续空间及堆叠容量。
- 拾荒者会巡逻、举枪、短点射和拉开交战距离。回响体更快，受声音吸引，靠近后发动近战。两者都需要视线才能对玩家攻击。
- 小刀每次出击都随身携带，不占背包。没有装备枪械时自动持刀，有枪时按 **3** 切刀。左键以 20 点伤害左右交替挥砍，收势末尾可预输入下一刀。右键蓄势后直刺，伤害为 46 点，收势更长。墙壁和掩体会挡住攻击，每次命中一个目标。
- 使用战术地图确认路线。进入撤离区后按 **E** 请求撤离，在区域内停留 6 秒。撤离成功后，装备和战利品保留在各自的槽位及格子中，可在整备页手动存回仓库。
- 阵亡、超时、主动弃离和刷新中断会丢失已带入战局的装备和物资。若信用点不足以买手枪且仓库与身上都没有枪械，可领取基础装备。出击时会在支持的浏览器上尝试进入网页全屏并锁定 Esc。短按 Esc 可开关暂停或关闭背包、容器，长按 Esc 由浏览器处理。全屏或键盘锁不可用时，会回退到普通鼠标锁定。若浏览器拒绝重新锁定，可点击「点击继续行动」恢复操作。

| 操作 | 按键 |
| --- | --- |
| 移动与观察 | WASD / 鼠标 |
| 奔跑、跳跃、蹲伏 | Shift / Space / C 或 Ctrl |
| 开火或轻击、瞄准或重刺、装填 | 左键 / 右键 / R |
| 切换主武器与副武器 | 1 / 2 或滚轮 |
| 切换简易小刀 | 3 |
| 搜索、打开遗落物资、请求撤离 | E |
| 手电筒、使用医疗品 | F / H |
| 使用已绑定的医疗品 | 4–7 |
| 背包、战术地图 | Tab / M（再按一次关闭） |
| 关闭面板、暂停 | Esc（有面板时只关面板；没有任何面板才暂停） |

## 项目结构

| 模块 | 职责 |
| --- | --- |
| `src/main.ts`、`input.ts` | 游戏状态、固定步长更新、Pointer Lock 和输入分派 |
| `src/sector.ts`、`collision.ts` | 地图布局、地图组件碰撞、视线射线和网格寻路 |
| `src/assets.ts`、`view.ts` | 程序化建筑、植被、容器与家具，分段人物，独立武器视图，光照、雾和特效池 |
| `src/player.ts`、`combat.ts`、`melee.ts`、`enemies.ts` | 移动、枪械与近战、受击和敌人状态机 |
| `src/data.ts`、`raid.ts`、`inventory.ts` | 物品和装备配置、行动流程、角色库存和装备转移 |
| `src/grid-inventory.ts`、`grid-inventory-ui.ts` | 网格坐标、合法性检测、堆叠和拖拽 |
| `src/inventory-screen.css`、`inventory-preview.ts` | 装备终端布局、可旋转角色和武器预览 |
| `src/save.ts` | 版本化存档、破损恢复、出击账目与救济 |
| `src/ui.ts`、`style.css`、`audio.ts` | 藏身处、HUD、战术地图、采样与合成音效 |
| `src/props.ts`、`icons.ts`、`assets/icons/` | 收集品的程序化模型、图标清单与渲染产物 |

场景采用低饱和色块、平面着色、模块化方块建模与正常的空间光照。主要静态几何按形状实例化，角色和枪械复用几何体与材质，四十八个弹着与曳光对象跨战局循环使用。人物通过独立的躯干、头部与四肢旋转实现姿态，无外部模型或骨骼绑定。

Remington 870 的概念稿、程序化模型配方和预览生成方式见 [资产制作](art/README.md)。

物品图标不是手绘的：`npm run icons` 打开一个独立的渲染舞台，把每件东西的模型拍成透明背景 PNG（枪用正交侧视、枪口向左，收集品用 28° 轻俯视 + 弱透视近似等轴测，方位 45°），存到 `assets/icons/`。改完模型或新增物品，跑一次就会重建全部图标和联系表 `art/previews/item-icons.png`。

## 资料库（wiki）

`npm run wiki` 会读 `src/data.ts` 与 `src/sector.ts`，生成 `wiki/index.html`（单文件、离线可开）和 `wiki/data.json`：物品图鉴（按分类/稀有度筛选、搜索、按价值或单格价值排序）、武器数值、护甲与医疗、每个容器的掉落概率与期望收益、商人货单、规则速查。

数据只有一处来源，改完数值重跑脚本即可，不需要手工同步文档。

## 验证

```sh
pnpm test
pnpm build
pnpm exec playwright install chromium --only-shell
pnpm test:e2e
pnpm build:offline
pnpm test:offline
```

规则测试覆盖容量和堆叠、装备兼容、地图可达性、碰撞和遮挡、掉落、存档迁移与恢复、跨局物资结算和救济。浏览器脚本会启动本地环境，运行真实的键鼠与指针锁定操作，并将截图写入 `test-output/`。浏览器测试也会将 `dist/` 挂到模拟仓库子路径并加载实际音频。单文件测试会在断网的 Chromium 中通过 `file://` 检查音频解码、开火和存档。Linux 上若缺少浏览器运行库，可安装 Playwright 所需的系统依赖。

## 设定与声音来源

环礁湾、潮汐异常、回响体、分类物资、商人和撤离经济参考同级项目《TidalLine》。站区布局、3D 模型、装备数值和前端实现为本项目独立制作。

从《TidalLine》复制的 WAV 文件位于 `src/audio/`。源与作者见 [音效来源](AUDIO_CREDITS.md)。脚步、枪声和敌人活动声会按相对位置调整音量和声像。其他提示音、手电操作反馈与环境底噪由 Web Audio 合成。
