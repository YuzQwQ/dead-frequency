# Dead Frequency / 死寂频段

桌面浏览器上的单人第一人称搜打撤游戏。第一次潮汐过后的第四年，环礁湾 07 号转播站重新发出了停播前的呼号。玩家从南侧道路入场，在 15 分钟的静潮窗口内搜索仓库、医疗站、调度楼、车间和信号研究室，并从北侧水闸或东侧公路撤离。

## 启动

### 双击离线版

在文件管理器中用桌面浏览器打开项目根目录的 `死寂频段.html`。这一个文件包含游戏代码、样式和音效，可以复制到其他目录并离线使用。离线存档由浏览器管理，一般与该文件的路径关联。移动或重命名文件后，原路径的存档可能不会显示。

修改源代码后，运行 `pnpm build:offline` 重新生成单文件。

### 本地开发与预览

需要 Node.js 22.12+ 和 pnpm 11。建议使用 Node.js 24。游戏需使用支持 WebGL 2 和 Pointer Lock 的桌面浏览器。

```sh
pnpm install --frozen-lockfile
pnpm dev
```

打开 Vite 打印的本地地址。首次出击时浏览器会锁定鼠标并启用声音。若自动锁定未获得许可，可点击「返回现场」重试。

```sh
pnpm build
pnpm preview
```

构建产物位于 `dist/`。可以把该目录放到任意静态 HTTP 服务的根路径或子路径。开发和构建需要安装依赖，构建后的游戏由本地打包的前端代码和音频运行。

## GitHub Pages

将本目录作为一个独立仓库的根目录推送至 `main`。在仓库 **Settings → Pages → Build and deployment → Source** 选择 **GitHub Actions**，随后运行 **Deploy Dead Frequency to Pages**。仓库里的工作流会安装锁定依赖、运行规则测试、构建并上传 `dist/`。Vite 的相对资源路径支持 `https://<账号>.github.io/<仓库名>/`。也可以把已构建的 `dist/` 发布到其他静态主机。

本地存档属于当前浏览器和站点来源。开发服务器、正式域名或不同端口各自保留自己的存档。

## 行动规则

- 在行动简报中看路线，在仓库装配主武器、副武器和护甲，并将对应弹药与医疗品装入背包。初始配置有手枪、轻甲和补给，仓库另有一把霰弹枪。
- 搜索要求面对可触及的容器并站定片刻。移动、偏离目标或受伤会打断搜索。容量按物品组计算，同口径弹药可堆叠。
- 物品栏统一用格子：单击看详情（分类、稀有度、重量、单价），右键出操作菜单，双击在容器与背包之间快速转移。仓库、交易和搜刮面板共用同一套操作。
- 仓库按堆计格，上限 90 格：可按分类筛选、按名称或描述搜索、按价值/稀有度/名称/重量排序，页脚显示当前结果的可回收估值。买入受容量限制，撤离带回允许溢出，超出后需要先出售。
- 拾荒者会巡逻、举枪、短点射和拉开交战距离。回响体更快，受声音吸引，靠近后发动近战。两者都需要视线才能对玩家攻击。
- 小刀每次出击都随身携带，不占背包。没有装备枪械时自动持刀，有枪时按 **3** 切刀。左键以 20 点伤害左右交替挥砍，收势末尾可预输入下一刀。右键蓄势后直刺，伤害为 46 点，收势更长。墙壁和掩体会挡住攻击，每次命中一个目标。
- 使用战术地图确认路线。进入撤离区后按 **E** 请求撤离，在区域内停留 6 秒。撤离时新回收的背包物资入库，仍穿戴的装备、枪械余弹与原有随身补给保留。
- 阵亡、超时、主动弃离和刷新中断会丢失已带入战局的装备和物资。若信用点不足以买手枪且仓库与身上都没有枪械，可领取基础装备。打开局内面板或失去鼠标锁定时，单机行动暂停。

| 操作 | 按键 |
| --- | --- |
| 移动与观察 | WASD / 鼠标 |
| 奔跑、跳跃、蹲伏 | Shift / Space / C 或 Ctrl |
| 开火或轻击、瞄准或重刺、装填 | 左键 / 右键 / R |
| 切换主武器与副武器 | 1 / 2 或滚轮 |
| 切换简易小刀 | 3 |
| 搜索、打开遗落物资、请求撤离 | E |
| 手电筒、使用医疗品 | F / H |
| 背包、战术地图 | Tab / M（再按一次关闭） |
| 关闭面板、暂停 | Esc |
| 物品操作 | 单击详情 · 右键菜单 · 双击转移 |

## 项目结构

| 模块 | 职责 |
| --- | --- |
| `src/main.ts`、`input.ts` | 游戏状态、固定步长更新、Pointer Lock 和输入分派 |
| `src/sector.ts`、`collision.ts` | 地图布局、地图组件碰撞、视线射线和网格寻路 |
| `src/assets.ts`、`view.ts` | 程序化建筑、植被、容器与家具，分段人物，独立武器视图，光照、雾和特效池 |
| `src/player.ts`、`combat.ts`、`melee.ts`、`enemies.ts` | 移动、枪械与近战、受击和敌人状态机 |
| `src/data.ts`、`raid.ts`、`inventory.ts` | 武器和掉落表、行动流程、容量、堆叠和装备转移 |
| `src/save.ts` | 版本化存档、破损恢复、出击账目与救济 |
| `src/ui.ts`、`style.css`、`audio.ts` | 藏身处、HUD、战术地图、采样与合成音效 |

场景采用低饱和色块、平面着色、模块化方块建模与正常的空间光照。主要静态几何按形状实例化，角色和枪械复用几何体与材质，四十八个弹着与曳光对象跨战局循环使用。人物通过独立的躯干、头部与四肢旋转实现姿态，无外部模型或骨骼绑定。

P-12 的概念稿、程序化模型配方和预览生成方式见 [资产制作](art/README.md)。

## 验证

```sh
pnpm test
pnpm build
pnpm exec playwright install chromium --only-shell
pnpm test:e2e
pnpm build:offline
pnpm test:offline
```

规则测试覆盖容量和堆叠、装备兼容、地图可达性、碰撞和遮挡、掉落、存档迁移与恢复、跨局物资结算和救济。浏览器脚本会启动本地环境，运行真实的键鼠与指针锁定操作，并将截图写入 `test-output/`。浏览器测试也会将 `dist/` 挂到模拟仓库子路径并加载实际音频。单文件测试会在断网的 Chromium 中通过 `file://` 检查音频解码、开火和存档。Linux 上若缺少浏览器运行库，可安装 Playwright 所需的系统依赖。

## 设定与声音来源

环礁湾、潮汐异常、回响体、分类物资、商人和撤离经济参考同级项目《TidalLine》。站区布局、3D 模型、装备数值和前端实现为本项目独立制作。

从《TidalLine》复制的 WAV 文件位于 `src/audio/`。源与作者见 [音效来源](AUDIO_CREDITS.md)。脚步、枪声和敌人活动声会按相对位置调整音量和声像。其他提示音、手电操作反馈与环境底噪由 Web Audio 合成。
